# Classifiedy Invoice v1.0
Classifiedy Invoice is a self-hosted billing platform developed by Classifiedy. It simplifies client CRM, quote creation, automated recurring invoicing, and payment tracking.

📦 Repository Assets
• Classifiedy Invoice v1.0.zip – Contains the complete, pre-configured source code application extracted from the production environment.
• DB.zip – Contains the matching SQL database schema snapshot and essential data tables required for deployment.

⏱️ Quick Deployment
1. Extract the App: Unzip Classifiedy Invoice v1.0.zip directly into your server's web root directory.
2. Restore the DB: Unzip DB.zip and import the extracted .sql file into a fresh MySQL/MariaDB database instances.
3. Link the Two: Edit the ipconfig.php file in the source root to update your DB_USERNAME, DB_PASSWORD, DB_DATABASE, and the app URL.
